APA 入站流水线

外部事件从进入 APA 到成为建议或挂靠到原事项的路径

统一流水线

  • • 三种来源只在入口不同，转换成标准事件后走同一条路
  • • 去重键为去重域加事件 id，事件落盘后才推进游标
  • • 原始 payload 落盘后才回 2xx，崩溃不丢事件

规则优先，模型兜底

  • • 规则能判定的不调模型
  • • 判断型只回枚举与置信度，低置信再升级
  • • 模型不可用时事件标记未判定，留在来源页，不丢

跟进消息不重复建事项

  • • 关联键命中已委派的未关闭事项才挂靠，命中多个或只命中已关闭时不猜
  • • 无人值守链路只转白名单发送者，其余只进 Web 与本人在场的主会话
  • • 挂靠消息一律不拉起新运行
