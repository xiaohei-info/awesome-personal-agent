APA 领域模型

账本实体、运行记录、判断记录、入站记录与配置之间的关系

建模原则

  • • 任务、承诺、决策、委派、简报都是 Item，用 kind 区分
  • • 扩展走 kind + spec + ext + tag + relation，不加字段设计器
  • • 事项与材料的关联是类型化 relation：依据、产出、纪要
  • • 每类数据只有一个写入模块，其他模块经命令模型调用

两类记录

  • • 账本事实：Item、Project、Material、Revision、Guideline、Timer、实例，变更都写 Event
  • • 运行队列：Delivery、Run、来源事件、判断记录、Ingest，有自己的状态字段，只把关键结果写 Event
  • • 判断记录不进 Event 日志：用到这次判断的命令在自己的 Event 载荷里引用它的 id（虚线）
  • • 账本事件与来源事件是两个概念，不能混用

只在 Web 设置

  • • 策略、信任级、token、ext 密钥、转发白名单
  • • 项目允许的执行者、规则 observe 与 auto 切换
  • • 判断端点与生成端点、不确定带与影子模式、抽检结论、外发范围
  • • 能力包不能修改以上任何一项
