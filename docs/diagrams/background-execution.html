APA 后台执行

无人值守运行的触发、两种运行者、委派回收与续接

两种运行者

  • • task：任务型专属 agent，在子事项上承担执行者角色
  • • main_session：主会话角色，读上下文后像本人回复时一样处理事项，把工作委派给执行者
  • • 带网关的 harness 可由插件声明改为唤醒真实主会话，与无头运行二者择一

内核强制的边界

  • • 运行凭据没有代答能力：不能决策，不能接受建议，需要决策时转 needs_input
  • • 只有转发白名单内发送者的跟进消息能进入无人值守链路
  • • 规则默认 observe，切换 auto 只在 Web
  • • 子事项 assignee 必须在项目允许的执行者范围内

位置与续接

  • • 只约束运行者进程本身在 APA 所在主机，实际工作经委派可在任何主机
  • • 同一事项同时只有一个运行；账本是真理源，harness 会话可丢失
  • • 不支持续接或会话失效时，用新会话加事项上下文
  • • 全程可经 apa why 回放
