APA 系统架构

账本、命令模型、时钟、Web 中台与 Agent 原生 CLI 的分层结构及外部集成

系统边界

  • • APA 边界内：接入层、内核与扩展层
  • • 边界外：外部扩展与 Agent Harness，独立运行
  • • 账本写入统一经由 HTTP API

内核对外接口

  • • 事件订阅：面向系统的稳定事件流
  • • 投递队列：面向渠道的提醒领取与送达回执
  • • 外部通知由消费方领取，内核不主动推送
  • • 健康视图：Web 与 CLI 统一呈现运行异常，只报不修

外呼与安全控制

  • • 外呼调用器：内核唯一外呼出口
  • • 外呼范围：模型调用与子进程运行
  • • 后台执行：主动服务触发，运行者分主会话角色与任务型
  • • 高风险决策与策略变更：仅限 Web 中台确认

扩展机制

  • • 能力包：声明式自动化定义，不含代码
  • • 外部扩展：独立密钥，按类型限权，可随时吊销
  • • Agent Harness：经通用接口接入，内核不依赖具体实现
