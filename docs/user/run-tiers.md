# 三档运行形态

APA 按你手里有什么分三档工作。每一档都是完整可用的产品形态，分别验收；前两档保证没有宿主、或宿主暂时不可用时产品仍然有用。

| 形态 | 需要 | 可用 | 不可用 |
|---|---|---|---|
| 只有内核 | APA 本身 | 账本、Web 工作台、来源与规则（含条件监视、摘要出口）、截止与跟进提醒、久未推进询问、渠道 ext、导出 | 语义筛选（规则判不了的事件留在积压里，由本人处理）、起草、简报、例行任务的执行 |
| 加模型端点 | 生成端点，判断端点可选 | 以上，加入站初筛与起草、对话候选抽取、web_only 初筛、决策卡片文案、摘要；简报与例行任务可改用生成型（不能查外部资料） | 需要工具的任务 |
| 加宿主 harness | 首批宿主及其插件 | 全部，含会话注入、聊天代答、委派与回执捕获、任务型、后台执行 | — |

本版面向已经在用 harness 的人，支持一个宿主，接口按多宿主设计；第二个宿主是本版之后的第一优先。

## 怎么知道自己在哪一档

运行 `apa doctor`，其中“运行形态”一项给出当前档位，并说明缺什么才到下一档。

## 常见问题

- **没有模型端点，规则判不了的事件去哪了？** 留在来源页的积压里，由你处理，不会丢。配置端点后可以按积压放开的四步（只跑规则、影子打分、定不确定带、按每日上限放开重判）逐步交给模型。
- **宿主暂时不可用会怎样？** 任务型运行拉不起来时，事项转 `needs_input`，级联终止，其他能力不受影响。
- **没有宿主能不能用外发渠道？** 能。渠道 ext 与宿主无关。
