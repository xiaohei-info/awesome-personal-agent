# 卸载

1. **留存数据（可选）**：需要留下数据时先 `apa backup create`，或保留导出目录。备份含来源凭据与接收密钥明文，按敏感数据保管。
2. **停止并移除系统服务**：停止 `apa serve`，移除你注册的系统服务单元（样例见 `deploy/systemd/`）。
3. **卸载宿主插件**：在用到的 harness 里卸载 APA 插件，连同它写入的常驻指令与钩子。
4. **吊销凭据**：在 Web 吊销全部 token 与 ext 密钥——或者直接执行下一步，数据目录一并删除。
5. **删除数据目录**：确认目录（默认 `~/.apa`，或你设置的 `APA_HOME`）里没有还要用的东西后再删除；其中含 `ledger.db`、`sources/`、`webhook-keys/` 与 `backups/`。
6. **外部工具的凭据**：来源适配用的邮件、日历、代码托管等工具自己的凭据不在 APA 的数据目录里，不受影响，请按各工具的方式清理。
7. 反向代理或隧道里为 APA 配的站点（样例在 `deploy/`）一并移除。

卸载不会向任何外部系统发送内容。
