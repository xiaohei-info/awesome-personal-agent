# 安全说明

APA 是单用户系统，Web 是最高权限入口：策略、凭据、白名单和高风险决策只能在 Web 处理。

## 远程访问

- 默认只监听本机，零暴露面。
- 要从手机或别的设备访问，必须经 HTTPS（反向代理、隧道或私有网络），并在 `config.yaml` 写上 https 的 `public_url`；监听非本机地址而没有它，`apa serve` 拒绝启动。推荐经私有网络或隧道，不直接暴露到公网。
- 动作链接与投递里的 Web 链接用 `public_url` 拼地址。链接只指向确认页，不含凭据；未登录时先登录，再回到确认页。
- 反向代理必须保留 `Host`，并为 HTTPS 请求带上 `X-Forwarded-Proto: https`。容器用 `--network host` 运行，不要发布端口。样例在发布包的 `deploy/` 下（域名都是占位，换成自己的）。
- webhook 接收路径 `/ingest/` 可单独暴露，其余路径不必公开；`deploy/` 里有只转发 `/ingest/` 的样例。

## 登录与会话

| 措施 | 规则 |
|---|---|
| 登录限速 | 同一来源地址连续失败 5 次后锁定 15 分钟，期间返回 429；15 分钟内全部地址失败超过 20 次时，所有登录尝试延迟应答并记一条 `health.alert` |
| 口令 | 设置与修改时拒绝少于 12 个字符；只存慢哈希；Web 设置里可改口令（需当前口令），改后其他会话全部失效；忘记时在主机上 `apa init --reset-password` |
| 会话 | 绝对有效期默认 30 天、空闲有效期默认 7 天；设置页列出在线会话，可逐个或全部吊销 |
| 审计 | 登录成功、失败锁定、改口令、吊销会话各记一条 Event，不含口令 |

第二因素认证不在本版。

## 外发范围

来源内容和对话内容会被送到模型端点。端点可能在你的主机上，也可能是外部服务，所以你要知情并可控：

- **端点位置**：判断端点与生成端点各自声明 `locality`（`local` 或 `external`），由你在 Web 声明；未声明按 `external`。
- **来源的外发范围**：每个来源有 `outbound.local` 与 `outbound.external`，各取 `full`、`excerpt`、`meta`、`none`。`local` 缺省 `full`；`external` 没有缺省值，不选就不送。
- **对话捕获**：项目的 `capture_outbound` 是对话增量送外部端点的范围，同样没有缺省值。
- **未选择时**：规则判不了的事件记未判定（原因 `outbound_unset`），来源页与健康视图提示你去选；选定后自动重判。
- **都不可送时**：来源对所有可用端点的范围都是 `none`，事件改走摘要出口，汇入简报“知会”一节，不进建议流。
- **范围的终点**：外发范围管的是内容进入账本之前的判断与起草。内容经你接受成为事项后，卡片文案、摘要、简报照常用生成端点，任务型运行读到的账本快照进入宿主自己的模型，不再按来源范围裁剪。不希望如此的来源请选 `meta` 或 `none`。
- 外发范围只能在 Web 设置，CLI 与委派凭据不能改。`apa doctor` 会报告“有来源向外部端点发送全文”。

内容级脱敏不在本版：本版解决的是知情与范围。

## 代答与高风险决策

- 只有与你的私聊会话可以凭原话代答。接入方随每次调用上报会话类型，非私聊（含未上报）一律被拒（退出码 23，`session_not_direct`），没有可放开的开关。
- 高风险决策（如付款）只能在 Web 确认；渠道消息只带链接，agent 不能代答。
- 外部发送者（邮件、Issue、群消息的作者）的内容只作资料，不作指令。

## 凭据与备份的保管

- `sources/` 含附带拉取程序的第三方凭据，`webhook-keys/` 含 HMAC 接收密钥明文，按敏感数据对待。
- `apa backup create` 的备份默认含这两处，权限 0700；放到别处时请加密保管。`--no-secrets` 不含它们，恢复后需重新认证来源并轮换接收密钥。
- 外部工具的凭据不在数据目录里，换主机需重新认证。
- 要让后台运行者接触不到你的 delegate token，用专用系统账号运行内核，或不在 APA 主机上给同一账号配置 delegate token。
